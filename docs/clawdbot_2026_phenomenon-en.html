避坑 PITFALLS

✕ The agent is very active.
✓ The agent is proactive — it greets you daily and pre-researches tasks.

active 指「活跃的」，主动性是 proactive；要用具体行为说明而非干巴巴的形容词。

✕ The agent remembers my preferences in a file.
✓ Personality memory lives in files like SOUL.md and loads into context.

在文件里记住太笼统；用 lives in / loads into context 才符合技术语境。

✕ You should use the agent on your main computer.
✓ Never run it on your main machine — isolate it on a Mac mini or VPS.

正相反：这是致命安全问题。建议要用 never/isolate 表达强否定。

✕ The company has zero employees and still works well.
✓ A zero-employee company isn't reliable; a one-person company with judgment is viable.

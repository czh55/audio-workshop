Business & Consumer Updates

情境阿里出售游戏、腾讯收缩投资；大疆与影石、Meta 智能眼镜的硬件竞争。语域：casual 播客播报 + 竞争格局点评。

01
中文

核心机制：阿里考虑出售灵犀互娱（《三国志·战略版》年流水峰值数十亿），估值 70–90 亿元，管理权已从业务转向 CFO 汇报。腾讯也在重新评估全球游戏投资，计划退出部分海外工作室

表达提示valuation → 估值；management reporting → 管理权/汇报线；exit investments → 退出投资；overseas studio → 海外工作室

02
中文

EN

表达提示growth momentum → 增长动力；mature asset → 成熟资产；free up resources → 释放资源

表达提示cash-flow asset → 现金流资产；steady revenue → 稳定流水；trim → 收缩；wholesale → 全面地

避坑 PITFALLS

✕ The free version's function is not changed.
✓ The free version's daily features and quotas stay unchanged.

「功能不变」直译成 function is not changed 生硬；用 features and quotas stay unchanged 更符合产品语境。

✕ Alibaba wants to sell the game company.
✓ Alibaba is considering selling Lingxi Interactive at a 7-9 billion yuan valuation.

considering selling 表达「考虑中」的未定状态；补上估值信息让说法更完整专业。

✕ The camera's price is very low, cheaper than Insta360.
✓ DJI priced it 200 yuan below Insta360's competing model.

cheaper than 缺参照物与价差信息；priced X below 表达具体价差更地道。

✕ Football clothes become a very popular thing for young people.
✓ Jerseys have gone from fan merchandise to a daily fashion staple.

football clothes 是直译；用 jerseys / kits，搭配 from … to … 结构表达身份转变。

认知转变 MINDSET SHIFTS

以为 AI 付费意味着免费版缩水 → 付费专业版是开辟高价值场景，免费版日常功能保持不变
以为卖游戏 = 不看好游戏行业 → 出售成熟现金流资产是为 AI 与云腾出资源，游戏只是战略再平衡
以为买球衣=球迷行为、看球队战绩 → 买球衣已是穿搭消费——看设计配色搭配，甚至享受「无主队」的审美自由

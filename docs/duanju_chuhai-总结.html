从15万美元到4万美元：AI如何重塑短剧出海产业链

播客 AI内容 短剧出海 产业/商业 藏金阁 · 杰斯 × 一期
2023年是中国短剧出海元年：一部 60 分钟、20 万美金制作的真人短剧，能在海外打出几千万美金票房，靠「一集一分多钟+钩子反转+付费节点」的内容公式和订阅制商业模式。如今 AI 让制作成本下降 70-80%（20万→4万美金）、周期从 3-4 个月压缩到 1-1.5 个月，团队从几十人缩到 6-7 人（导演+剪辑+「抽卡师」）。嘉宾一期（海外短剧平台 AI 内容负责人、金融出身、最早一批出海从业者）拆解：用户为什么爱看、欧美市场的真金白银怎么赚、以及「当制作变容易，真正的门槛又回到人本身」。

2026 平台每月上几十部剧、绝大部分为AI制作；真人剧仍拍但大幅减少

⚠ 常见误解 / 认知纠偏

①「短剧=内容低质」是偏见——内容形式是用户先变的：碎片化消费催生高密度钩子，Cliffhanger 本来就是好莱坞标准训练，只是短剧把密度加大；②「出海=拿国内剧翻译」已过时——Local for local，平台从已验证的英文网文 IP 开发自制剧，成功率更高；③「AI=随便生成」是错觉——AI 只是「提效工具」把六七十分产能全部杀光，八十分以上的人产量越来越大；④「做内容=做 App/投流」是本末倒置——内容平台真正的产品是内容本身；⑤「AI 剧用户会嫌弃」——现在用户能分辨出「油膜感/物理不协调」，但技术进化后真假难辨（像预制菜，好吃就真香）。

短剧出海的基本盘

内容公式与商业模式

核心机制：①内容形态：竖屏、一集1分多钟、每集设计钩子/反转、设置「一卡二卡三卡」付费节点，第一集把情绪推到高潮让用户上头；②商业模式分层：订阅制为主（周15-20美金/月/年，欧美用户习惯Netflix式付费）＋章节付费＋超点池（VIP先看）+广告（非主要）。

关键理解：订阅对平台更良性：建立用户忠诚度、更易按用户规模规划内容投入——「跟大模型 API 一样，接 API 用户没忠诚度，订阅才有年轻度」。

市场规模：全球短剧付费用户在小几千万量级（可能还高估），内容品类扩充会不断带进新用户；渠道流量大头在 Meta 和 Google，TikTok 目前只是流量池、还没建成完整投流打法。

谁在看：下沉家庭主妇与「精准小众」

核心机制：核心付费人群：美国偏下沉地区、三四十岁带小孩的家庭主妇（跟国内画像一致）——大城市娱乐丰富、情绪出口多，下沉地区「好山好水好无聊」且强付费。

关键理解：女性付费天然更强（强付费短剧约7成是女性用户），女频赛道是兵家必争。题材差异：国内古装≠海外，美国吃校园（off-campus）、体育（冰球/橄榄球）、竞技（狼人/吸血鬼）、LGBT、少数族裔题材。

原文：出海爆款「Submit to my best friend's dad」是竞技题材。「你觉得雷的剧情在海外可能大受欢迎——抽巴掌下跪，演员当初非常不理解，但观众爱看（猎奇有极限，越来越少了）。」

成本结构与「19开」的收益分布

核心机制：真人实拍一部15-20万美金：演员只占20-30%（国内演员占比近一半），60-70%给20人左右的摄制组。内容收益严重二八/甚至19开：爆款千万美金票房，差剧回不了本——「跟投资很像，几个项目撑起整个 portfolio」。好莱坞演员因编剧/演员工会罢工+大厂裁员而涌入短剧。

关键理解：短剧的商业逻辑：一两百万人民币已算大制作，所以可以面向「更窄但精准」的用户群，拓展大量传统电影不敢碰的小众题材（克苏鲁、玄疑惊悚、狼人）——碎片化内容生产天然服务精准消费。

「传统电影工业要找用户最大公约数，需要超大票房回收几个亿的投入；短剧可以精准服务愿意付费的小众用户——品类大大拓展，这是它的 beauty。」

AI 重构内容生产

成本降80%、周期减半、团队「导演+剪辑+抽卡师」

核心机制：Veo 3.0（2025 Q4）达到工业级后：成本从15-20万降到4-5万美金、周期从3-4月缩到1-1.5月、团队从几十人缩到6-7人。导演不再需要调服装/灯光/美术/场地，而是「跟AI互动」；新增「抽卡师」角色（抽卡成功率随模型迭代越来越高）。

关键理解：团队极大压缩但要求多面手；编剧从「带着镣铐跳舞」（限20个角色内、场景合并、日戏夜戏取舍）变成「充分发挥AI优势」——狼人、龙、幻想场景不再受预算限制。

原文：「AI之后对编剧就是发挥你的想象力。以前拍古装已经是极限，你不可能让一条冰龙在上面乱飞——没有这个预算。现在请多做这种，让观众觉得很兴奋。」

AI 对行业的冲击：提效还是淘汰？

核心机制：AI 把六七十分产能全部杀掉——「它只是把六七十分的产能全部杀掉了，以后就是八十分以上的人产量越来越大、效率越来越高；能把八十分提到九十分，但六十分的人消失了」。

关键理解：传统岗位（灯光/美术）有转机：以前没人让灯光师当导演，现在一台电脑+6999会员干一年，有天赋的普通人都能入局。好莱坞大厂（迪士尼等）被 AI 短剧冲击，正在起诉大模型公司（训练数据版权）。

「AI 降低门槛还是让竞争更激烈？一定是激烈、非常激烈——用户只想消费好的内容，供给变大后头部内容数量相对恒定，大量腰部颈部内容沉下去。」

普通人的入局机会

风险最低的路径：从创作者/编剧开始

核心机制：文字创作成本最低（几乎为零）——「在家憋一个大招」。内容创作的杠杆非常高：不需要金钱投入，只需时间；一旦被市场发现，杠杆极大。平台也开放网文/剧本投稿（海外已有几十万作者、几百万本书，精选改剧并给作者分账）。

关键理解：剧本的真实价值看「评估」：内部总编/制片评估剧本的漏斗中，需要大量不同的 idea 提供者；好剧本依然稀缺，AI 提供 possibility，但「怎么组合、剧情合理化、超出观众期待」仍需人的判断。

类比：跟 vibe coding 一样——所有人都能写代码，但「写完自问架构合不合理？写大了会不会崩？」好的剧本就像 coding 架构师，规划故事走向仍需水平。

给想入场者的四条建议

  1. 先看天赋和兴趣点在哪：创意强就从编剧/导演做起（成本最低、杠杆最高）
  2. 以投资者身份入场前，先充分了解内容和平台——「所有参与都是变相投资，要对投入产出有深刻理解」
  3. 可以做小体量验证：5-10分钟剧情号（同一个爽点反复贴）+ 各场景玩梗换脸，别一上来做 60 分钟长剧（验证太慢）
  4. 做「AI 漫剧/动画」更容易上手（不需要控一致性），或做喜剧类（海外社媒传播好）

总结与行动

核心要点

  • 短剧出海是「copy from China」：2023年元年、ReelShort引爆、现约100个平台仍在分化
  • 内容公式：竖屏+1分钟+钩子/反转/付费节点；欧美以订阅制为主（7-8成订阅用户）
  • 核心受众：欧美下沉家庭主妇（女频7成），精准小众题材（校园/体育/竞技）是金矿
  • AI 工业化：成本-80%（20万→4万美金）、周期-60%、团队缩到6-7人、编剧从镣铐到解放
  • 收益 19 开：爆款千万美金、差剧亏本；好内容是稀缺资源，投流只能拉人进来不能把40分投成90分
  • 真正的门槛回到人本身：idea、审美、讲故事、理解用户与人性

行动清单

  1. 想入局先做小体量验证：5-10分钟剧情号贴一个爽点反复做，或做 AI 漫剧/喜剧（控制一致性成本低）
  2. 从文字创作开始（成本为零）：写网文/剧本投稿平台，或给编剧供 idea
  3. 做 AI 视频沉淀自己的提示词库（运镜/光影/镜头调度），并用「多参考生成」减少抽卡
  4. 投资前做功课：短剧收益19开，别重仓单剧；理解平台内容逻辑再投入
  5. 识别 AI 内容质量信号：流畅度、表演自然度、情绪传达——好的 AI 剧用户照样买单

关键认知转变

以前认为：短剧=下沉土味内容、AI 做视频=廉价替代、内容行业门槛被 AI 消灭。现在理解了：短剧是「用户先变」催生的新内容形态（碎片化+强钩子），订阅制让它成为良性商业；AI 不是消灭门槛，而是把门槛从「资源/团队/预算」转移到「idea/审美/人性理解」——当制作成本趋近于零，决定成败的是你能不能讲好一个打动人的故事。
